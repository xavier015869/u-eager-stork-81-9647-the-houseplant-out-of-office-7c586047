The Houseplant Out-of-Office: the funniest out-of-office auto-reply a houseplant
would send, in 120 characters or fewer. The entry is a fern, ignored since
March, thriving on spite, waiting for a sun that will not move.

## Run

```sh
node main.ts
```

This writes the entry to `/output/entry.txt`.

## Entry

> Out of office: I'm the fern. Ignored since March, thriving on spite. I'll reply when the sun moves. It won't.
